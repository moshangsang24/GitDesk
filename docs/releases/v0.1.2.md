# GitDesk v0.1.2

适用于 Apple Silicon Mac（arm64）的预发布版本。

## 本版更新

- **History** 默认显示紧凑的提交图，为标题留出更多空间。宽图可从列头展开。选择 **Compare release targets**，可查看当前工作树与 Test、Staging、Master 各自独有的提交并定位到图上。
- **Releases** 把目标分支放在列头，用图标和提交数量显示各阶段的包含情况。任务号、提交证据和 Fetch 新鲜度可以在同一页查看。
- **建任务** 以选择的 Source 分支和配置的 Master 生成候选。候选完整且没有预选提交时会全选，仍可取消勾选。单条记录可填写多个任务号，同一个号码可用于多条记录。
- **发布证据** 支持把经人工核对的 squash 或 cherry-pick 提交关联到原提交。阶段状态基于本机 Git 引用快照，实际部署状态以发布系统为准。
- **仓库网络** 可沿用 Git 设置、直连或使用自定义代理。设置按仓库保存，适用于 HTTP(S) 的 Fetch、Pull 和 Push。
- 修复原生右键菜单连续使用时复制分支名失效的问题。

## 安装与升级

打开 `GitDesk_0.1.2_aarch64.dmg`，将 `GitDesk.app` 拖入 Applications。升级时先退出正在运行的 GitDesk，再替换旧 App。应用沿用原有本地配置。保存自定义代理设置或人工提交关联后，旧版使用该配置会提示需要更新。

本包使用 ad hoc 临时签名，Apple Developer ID 签名和 Apple 公证尚未提供。macOS 可能阻止从互联网下载的 App 启动。随包提供 SHA-256 校验文件，第三方许可说明位于应用资源内。
